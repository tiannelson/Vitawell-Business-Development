While writing my GRASP brief for Cowork and Code, there were some similarities and a few differences between what I wanted, what I used, and what I did to reach my goal. My goal for Cowork was ultimately creating the information that I needed to be able to use to create my dashboard. Since it was a made-up business, I was able to use cowork to create some hypothetical files for if the company existed. The Code stage was essentially used to bring all that data to life in an easy to use, interactive dashboard anyone can pull up and look at. It gathers all the information from my Cowork, organizes it, and compiles into easy-to-read sections.  I think my goal is the part that changed the post between the two as they were both built for different things. Stage 1, create, stage 2, build. A moment I had to correct or override is really when I was using cowork to compile files it was just adding unnecessary information that I did not want to include in my Code. So, the files I used to create the compiled information I essentially took out some additional files I did not think were relevant. Another step I had to correct in Code could not allow it to push to Github on its own, so I saved the files and uploaded them manually and asked code to create steps based on that foundation. I'd trust this tool unsupervised for mechanical, checkable work with objective pass/fail criteria, converting formats, verifying output, especially when the result stays internal for human review before it goes anywhere. I would not trust it unsupervised for anything with real financial, legal, or client-facing stakes, anything requiring business judgment rather than internal consistency, or anything where it might silently change assumptions or hit flaky infrastructure without a person noticing. This is a great tool for internal meetings just to give a brief understanding about where were at and where we want to go within the company. The general pattern is reversible, checkable, low-consequence work is a reasonable place to let this run on its own.
